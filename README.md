# Landing Pages & Systems

A focused 30-day sales pilot for independent paver and hardscaping contractors in Tampa Bay.

- [Open the dashboard](https://arthurlaragao.github.io/side-hustle-30-dias/) to work through the checklist, price a job and see the daily research targets.
- [Read the 30-day plan](30-DAY-PLAN.md) for daily actions, cumulative targets and the US$10,000 stretch scenario.
- Track companies, outreach, markets, projects, ideas and cleared payments in your private Notion project.

Checklist edits live in browser storage. Use **Backup** to export or merge JSON when switching browsers. Older v3 records remain in the full export, and v1/v2 imports preserve the source snapshot. The active checklist and its progress cover only this pilot.

Open `index.html` or serve the repository root over HTTP. GitHub Pages publishes `main` from the root. Run `node tests/verify.cjs` to verify backup compatibility, checklist persistence, visible views, quote calculations and daily quotas.
